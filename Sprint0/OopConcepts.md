# Sprint 0 — Task 1

## Основные понятия и концепции ООП

### 1. Класс

**Класс** — это описание объекта, в котором задаются его свойства и методы.

Например, можно создать класс `Car`, который описывает автомобиль:

```csharp
class Car
{
    public string Brand;
    public void Drive()
    {
        Console.WriteLine("Автомобиль едет");
    }
}
```

Здесь `Car` — класс.

### 2. Объект

**Объект** — это конкретный экземпляр класса.

Например:

```csharp
Car car = new Car();
```

Здесь `car` — объект класса `Car`.

Можно создать несколько объектов одного класса:

```csharp
Car car1 = new Car();
Car car2 = new Car();
```

Оба объекта относятся к одному классу, но являются разными объектами.

### 3. Свойства

**Свойства** используются для хранения и получения данных объекта.

Например:

```csharp
class Car
{
    public string Brand { get; set; }
    public int Year { get; set; }
}
```

У объекта `Car` есть свойства `Brand` и `Year`.

Использование:

```csharp
Car car = new Car();

car.Brand = "Toyota";
car.Year = 2025;
```

### 4. Методы

**Метод** — это действие, которое может выполнять объект.

Например:

```csharp
class Car
{
    public void Drive()
    {
        Console.WriteLine("Автомобиль едет");
    }
}
```

Вызов метода:

```csharp
Car car = new Car();
car.Drive();
```

Результатом будет:

```text
Автомобиль едет
```

### 5. Инкапсуляция

**Инкапсуляция** — это объединение данных и методов внутри класса и ограничение прямого доступа к внутренним данным объекта.

Например:

```csharp
class BankAccount
{
    private decimal balance;

    public void Deposit(decimal amount)
    {
        if (amount > 0)
        {
            balance += amount;
        }
    }
}
```

Поле `balance` объявлено как `private`, поэтому напрямую изменить его из другого класса нельзя.

### 6. Наследование

**Наследование** позволяет создать новый класс на основе существующего.

Например:

```csharp
class Animal
{
    public void Eat()
    {
        Console.WriteLine("Животное ест");
    }
}

class Dog : Animal
{
    public void Bark()
    {
        Console.WriteLine("Собака лает");
    }
}
```

Класс `Dog` наследуется от класса `Animal` и получает его метод `Eat()`.

### 7. Полиморфизм

**Полиморфизм** позволяет использовать общий интерфейс для объектов разных классов.

Например:

```csharp
class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Звук животного");
    }
}

class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Гав");
    }
}

class Cat : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Мяу");
    }
}
```

Теперь разные объекты могут по-разному выполнять один и тот же метод `MakeSound()`.

### 8. Абстракция

**Абстракция** — это выделение главных характеристик объекта и скрытие ненужных деталей его реализации.

Например:

```csharp
abstract class Animal
{
    public abstract void MakeSound();
}
```

Абстрактный класс определяет общую идею поведения, а конкретные классы самостоятельно реализуют этот метод.

## Итог

Основные понятия ООП:

| Понятие      | Значение                                              |
| ------------ | ----------------------------------------------------- |
| Класс        | Описание объекта                                      |
| Объект       | Экземпляр класса                                      |
| Свойство     | Данные объекта                                        |
| Метод        | Действие объекта                                      |
| Инкапсуляция | Скрытие внутренних данных и управление доступом к ним |
| Наследование | Создание класса на основе другого класса              |
| Полиморфизм  | Разное поведение объектов через общий интерфейс       |
| Абстракция   | Выделение главных характеристик и скрытие деталей     |
